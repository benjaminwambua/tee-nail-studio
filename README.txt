TEE Nail Studio — Website
===========================

Files:
- index.html
- styles.css
- script.js
- assets/hero.jpg
- assets/gallery-1.jpg ... gallery-6.jpg
- assets/why-tee.jpg

How to open:
1. Keep the folder structure intact.
2. Double-click index.html, or right-click it and choose Open with your browser.

Before publishing:
1. Open script.js and replace CONFIG.whatsappNumber with the real WhatsApp number (digits only, including country code).
2. Replace the placeholder contact details in index.html.
3. Replace the concept gallery images in assets/ with TEE Nail Studio's actual work.
4. Update the Instagram link in index.html.
5. For a live site, upload the folder to a static host such as GitHub Pages, Netlify, Vercel, or your web host.

The site is intentionally dependency-light: HTML + CSS + vanilla JavaScript.
